# Посмотри в окно

Статическая страница по учебному макету.

## 📌 О проекте
Проект сверстан по учебному макету.  
Сделана аккуратная семантическая разметка и структурированы блоки.  
Цель — отработка навыков HTML и CSS, работа с сеткой и контентом на странице.

## 🛠 Использованные технологии
- HTML5
- CSS3
- Flexbox
- БЭМ-методология

## ⚙ Реализовано
- Семантическая разметка
- Работа с изображениями
- Стилизация блоков и текста
- Hover-эффекты для интерактивных элементов (кнопки, ссылки)
- Чистая структура классов
